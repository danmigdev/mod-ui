One rig. Two independent chains.

  1. In Perform, click Next on Microphone. Guitar keeps its preset.
  2. Select a different Guitar preset. Watch the previous reverb tail retire.
  3. Recall Chorus to select both chains together.
  4. In Preset library, edit Vocal Dry. Verse and Chorus share that definition.
  5. In MIDI switches, choose each switch's target and action, then Apply assignments.

This prototype demonstrates the workflow. It does not process sound or communicate with a controller.
